## ❤️ はじめに

今から10年ほど前、まだWeb版のQQを使っていた頃には、すでに酷狗（クゴウ）音楽を使い始めていました（もう十数年来の古くからのファンです）。だから、この何年もかけてお気に入りに登録した曲はすべてそこにあります。その後、NetEase Cloud Music や QQ 音楽も試してみて、酷狗のプレイリストをインポートしようとしましたが、結果はどれもいまいちでした。私がよく聴くのは日本のアニメのOPで、多くの曲が見つからなかったのです。

あちこち回り道をした末に、結局は酷狗に戻ってきました。ただ、Mac版の酷狗は時々再生できないことがあります。インターフェースに機能はほとんどありませんが、それでもなかなか良いものです。ネットの友人の勧めで、今はずっと酷狗の[コンセプト版](https://t1.kugou.com/d2tBza3CSV2)で音楽を聴いています。これは市井でも数少ない、VIP曲を無料で聴ける音楽再生ソフトのひとつで、強くおすすめします。

私は自己紹介ページに、音楽を聴くのが特に好きで、とりわけ日本のアニメのOPが好きだと書いています。どうやって証明するのか？（以前のWeb版プレイリストもずっと放置していましたが）それなら自分で音楽プレイヤーを作ってしまおう、と。

## 📦️ インストール

### 1. クライアントのインストール

本プロジェクトの [Releases](https://github.com/MoeKoeMusic/MoeKoeMusic/releases) ページにアクセスして、インストーラーをダウンロードしてください。

### 2. Web版のインストール（docker）

* 注意：デプロイ後にサーバーの対応ポートを開放しないと利用できません。または、リバースプロキシを使ってドメインでアクセスしてください。

    1. 方法その1：クイックスタート（推奨）

    ```
    git clone --depth=1 https://github.com/MoeKoeMusic/MoeKoeMusic.git
    cd MoeKoeMusic
    docker compose up -d &
    ```

    2. ~~方法その2：docker-compose でワンクリックインストール（イメージはまだ公式にアップロードされていません）~~
    
    ```
    docker run -d --name MoeKoeMusic -p 8080:8080 -e PORT=6521 -e platform=lite iajue/moekoe-music:latest
    ```

    3. 方法その3：宝塔（BT）パネルのコンテナオーケストレーション

    * リモートイメージのため、バージョンが公式より遅れる場合があります
    
    ```
    version: '3.3'
    
    services:
      moekoe-music:
        # イメージアドレス
        image: registry.cn-wulanchabu.aliyuncs.com/youngxj/moekoe-music:latest
        container_name: moekoe-music # コンテナ名
        restart: unless-stopped # 自動再起動
        build:
          context: .
          dockerfile: Dockerfile
        environment:
          - PORT=6521
          - platform=lite
        ports: # ポートマッピング
          - "8080:8080"  # フロントエンドサービス
          - "6521:6521"  # APIサービス
    
    ```
    
    上記の内容をコピーして宝塔パネルのコンテナオーケストレーションに貼り付け、オーケストレーション名を `MoeKoeMusic` にして、「デプロイ」をクリックします。

### 3. ワンクリックデプロイ
[![EdgeOne Pages でデプロイ](https://cdnstatic.tencentcs.com/edgeone/pages/deploy.svg)](https://edgeone.ai/pages/new?template=https://github.com/MoeKoeMusic/MoeKoeMusic&install-command=npm%20install&output-directory=dist&root-directory=.%2F&build-command=npm%20run%20build&env=VITE_APP_API_URL)

## ⚙️ 開発

1. リポジトリをクローン

```sh
git clone --depth=1 https://github.com/MoeKoeMusic/MoeKoeMusic.git
```

2. ディレクトリに移動して依存関係をインストール

```sh
cd MoeKoeMusic
npm install
```
3. 開発者モードを起動
  - ブラウザで開発
  ```sh
  npm run dev
  ```
  - クライアントの開発モードで開発
  ```sh
  npm run dev:client
  ```

4. フロントエンドをビルド
対象プラットフォームに応じて、以下のいずれかのコマンドでフロントエンドをビルドします
```sh
npm run build # Web用のフロントエンドをビルド
npm run build:client # クライアント用のフロントエンドをビルド
npm run build:docker # Dockerイメージ用のフロントエンドをビルド
```
5. プロジェクトをコンパイル
  - Windows: 
```sh
npm run electron:build:win # [デフォルトは NSIS インストーラー]
```
  - Linux: 
```sh
npm run electron:build:linux # [デフォルトは AppImage 形式]
```
  - macOS: 
```sh
npm run electron:build:macos # [デフォルトは macOS のデュアルアーキテクチャ]
```


その他のコマンドは `package.json` ファイルの `scripts` を参照してください。

## 👷‍♂️ クライアントのビルド

Releases ページにご自身のデバイスに合うインストーラーが見つからない場合は、以下の手順でご自身のクライアントをパッケージできます。

1. [Node.js](https://nodejs.org/en/) をインストールし、`Node.js` のバージョンが 18.0.0 以上であることを確認します。

2. `git clone --depth=1 https://github.com/MoeKoeMusic/MoeKoeMusic.git` で本リポジトリをローカルにクローンします。

3. `npm install` でプロジェクトの依存関係をインストールします。

4. `npm run build:client` を使ってクライアント用のフロントエンドをビルドする

5. 以下のコマンドから適したものを選んでインストーラーをパッケージします。出力されたファイルは `/dist_electron` ディレクトリにあります。詳しくは [electron-builder のドキュメント](https://www.electron.build/cli) をご覧ください。


#### 1. macOS プラットフォーム向けのパッケージ
   - ユニバーサルな macOS パッケージ（Intel と Apple Silicon のデュアルアーキテクチャ）：
   ```
   npm run electron:build -- --mac --universal
   ```
   - Intel アーキテクチャのみ：
   ```
   npm run electron:build -- --mac --x64
   ```
   - Apple Silicon アーキテクチャのみ：
   ```
   npm run electron:build -- --mac --arm64
   ```


#### 2. Windows プラットフォーム向けのパッケージ

   - デフォルトの NSIS インストーラー（ほとんどの Windows ユーザーに適しています）：
   ```
   npm run electron:build -- --win
   ```
   - Windows 用の EXE ファイルと Squirrel インストーラーを作成：
   ```
   npm run electron:build -- --win --ia32 --x64 --arm64 --target squirrel
   ```
       - `--ia32` は 32 ビット Windows アーキテクチャです。
       - `--x64` は 64 ビット Windows アーキテクチャです。
       - `--arm64` は ARM Windows アーキテクチャ（Surface などのデバイス）です。

   - Windows 用のポータブル EXE ファイルを生成（インストール不要）：
   ```
   npm run electron:build -- --win --portable
   ```
#### 3. Linux プラットフォーム向けのパッケージ
   - デフォルトの AppImage 形式（ほとんどの Linux ディストリビューションに適しています）：

   ```
   npm run electron:build -- --linux
   ```
   - snap（Ubuntu および snap をサポートするディストリビューション向け）：
   ```
   npm run electron:build -- --linux --target snap
   ```
   - deb（Debian／Ubuntu 系向け）：
   ```
   npm run electron:build -- --linux --target deb
   ```
   - rpm（Red Hat／Fedora 系向け）：
   ```
   npm run electron:build -- --linux --target rpm
   ```
   - ARM64 アーキテクチャ（ARM v8 以上）： 
   ```
   npm run build:api:linux-arm64 // APIをビルド
   npm run electron:build:linux-arm64 // メインプログラムをビルド
   ```

#### 4. すべてのプラットフォーム向けのパッケージ

  Windows、macOS、Linux のインストーラーを同時に生成する必要がある場合は、以下のコマンドを使用できます：
  ```
  npm run electron:build -- -mwl
  ```

#### 5. カスタムビルド設定

  必要に応じて他のオプションを追加し、パッケージをさらにカスタマイズできます。たとえば x64 と arm64 アーキテクチャを指定したり、異なるターゲット形式を選択したりできます。
