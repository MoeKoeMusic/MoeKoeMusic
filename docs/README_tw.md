## ❤️ 前言

早在十年前左右，那時候在用網頁版 QQ 的時候我就已經開始使用酷狗音樂了（也是十來年的老粉了），所以這些年收藏的歌曲全部都在上面。後來我也嘗試開始使用網易雲或 QQ 音樂，也嘗試把酷狗的歌單匯入進去，但是效果都不盡人意。我聽的大多是日漫 OP，好多歌曲都沒辦法找到。

兜兜轉轉最後還是回到酷狗，但是在 Mac 端的酷狗，時常可能會出現不能播放的情況，雖說介面沒什麼功能，但也挺好的。在網友的安利下，我現在一直是在酷狗的[概念版](https://t1.kugou.com/d2tBza3CSV2)上聽歌，並且是市面上為數不多能免費聽 VIP 歌曲的音樂播放軟體了，力推。

我在我的個人介紹頁面說我特別喜歡聽歌，尤其是日漫 OP。怎麼證明呢？（之前我網頁版歌單也年久失修了）那就自己開發一個音樂播放器。

## 📦️ 安裝

### 1. 客戶端安裝

造訪本專案的 [Releases](https://github.com/MoeKoeMusic/MoeKoeMusic/releases) 頁面下載安裝包。

### 2. WEB 端安裝（docker）

* 注意：部署後請開放伺服器對應連接埠才可使用，或者使用反向代理實現網域存取。

    1. 方式一：快速啟動（推薦）

    ```
    git clone --depth=1 https://github.com/MoeKoeMusic/MoeKoeMusic.git
    cd MoeKoeMusic
    docker compose up -d &
    ```

    2. ~~方式二：使用 docker-compose 一鍵安裝（映像檔暫未上傳官方）~~
    
    ```
    docker run -d --name MoeKoeMusic -p 8080:8080 -e PORT=6521 -e platform=lite iajue/moekoe-music:latest
    ```

    3. 方式三：寶塔容器編排

    * 遠端映像檔，版本可能會落後於官方
    
    ```
    version: '3.3'
    
    services:
      moekoe-music:
        # 映像檔位址
        image: registry.cn-wulanchabu.aliyuncs.com/youngxj/moekoe-music:latest
        container_name: moekoe-music # 容器名稱
        restart: unless-stopped # 自動重啟
        build:
          context: .
          dockerfile: Dockerfile
        environment:
          - PORT=6521
          - platform=lite
        ports: # 連接埠對應
          - "8080:8080"  # 前端服務
          - "6521:6521"  # 介面服務
    
    ```
    
    複製上面的內容，貼到寶塔面板的容器編排裡面，編排名稱為 `MoeKoeMusic`，點擊部署即可。

## ⚙️ 開發

1. 複製本儲存庫

```sh
git clone --depth=1 https://github.com/MoeKoeMusic/MoeKoeMusic.git
```

2. 進入目錄並安裝依賴

```sh
cd MoeKoeMusic
pnpm install --frozen-lockfile
```
3. 啟動開發者模式
  - 在瀏覽器裡開發
  ```sh
  pnpm run dev
  ```
  - 在客戶端開發模式下開發
  ```sh
  pnpm run dev:client
  ```

4. 建置前端
為你的目標平台選擇一條指令來建置前端
```sh
pnpm run build # 為網頁端建置前端
pnpm run build:client # 為客戶端建置前端
pnpm run build:docker # 為 Docker 映像檔建置前端
```
5. 編譯專案
  - Windows: 
```sh
pnpm run electron:build:win # [預設 NSIS 安裝包]
```
  - Linux: 
```sh
pnpm run electron:build:linux # [預設 AppImage 格式]
```
  - macOS: 
```sh
pnpm run electron:build:macos # [預設 macOS 雙架構]
```


更多指令請查看 `package.json` 檔案 `scripts`

## 👷‍♂️ 編譯客戶端

如果在 Release 頁面沒有找到適合你裝置的安裝包的話，你可以根據下面的步驟來打包自己的客戶端。

1. 安裝 [Node.js](https://nodejs.org/en/)，並確保 `Node.js` 版本 >= 20.0.0。

2. 使用 `git clone --depth=1 https://github.com/MoeKoeMusic/MoeKoeMusic.git` 複製本儲存庫到本機。

3. 使用 `pnpm install --frozen-lockfile` 安裝專案依賴。

4. 使用 `pnpm run build:client` 為客戶端建置前端

5. 選擇下列的指令來打包適合你的安裝包，打包出來的檔案在 `/dist_electron` 目錄下。了解更多資訊可造訪 [electron-builder 文件](https://www.electron.build/cli)


#### 1. 打包 macOS 平台
   - 通用的 macOS 包（Intel 和 Apple Silicon 雙架構）：
   ```
   pnpm run electron:build -- --mac --universal
   ```
   - 僅 Intel 架構：
   ```
   pnpm run electron:build -- --mac --x64
   ```
   - 僅 Apple Silicon 架構：
   ```
   pnpm run electron:build -- --mac --arm64
   ```


#### 2. 打包 Windows 平台

   - 預設 NSIS 安裝包（適合大多數 Windows 使用者）：
   ```
   pnpm run electron:build -- --win
   ```
   - 為 Windows 建立 EXE 檔案和 Squirrel 安裝包：
   ```
   pnpm run electron:build -- --win --ia32 --x64 --arm64 --target squirrel
   ```
       - `--ia32` 為 32 位元 Windows 架構。
       - `--x64` 為 64 位元 Windows 架構。
       - `--arm64` 為 ARM Windows 架構（Surface 等裝置）。

   - 為 Windows 產生可攜式的 EXE 檔案（免安裝）：
   ```
   pnpm run electron:build -- --win --portable
   ```
#### 3. 打包 Linux 平台
   - 預設 AppImage 格式（適用於大多數 Linux 發行版）：

   ```
   pnpm run electron:build -- --linux
   ```
   - snap（適用於 Ubuntu 和支援 snap 的發行版）：
   ```
   pnpm run electron:build -- --linux --target snap
   ```
   - deb（適用於 Debian/Ubuntu 系列）：
   ```
   pnpm run electron:build -- --linux --target deb
   ```
   - rpm（適用於 Red Hat/Fedora 系列）：
   ```
   pnpm run electron:build -- --linux --target rpm
   ```
   - ARM64 架構（ARM v8+）: 
   ```
   pnpm run electron:build:linux-arm64
   ```

#### 4. 打包所有平台

  如果需要同時產生 Windows、macOS 和 Linux 的安裝包，可以使用以下指令：
  ```
  pnpm run electron:build -- -mwl
  ```

#### 5. 自訂編譯設定

  您可以根據需要新增其他選項來進一步自訂打包，例如指定 x64 和 arm64 架構，或選擇不同的目標格式。
